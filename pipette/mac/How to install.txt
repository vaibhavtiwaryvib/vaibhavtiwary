Pipette 1.3 – statistics & graphs for lab data
Published by VITIRAN
================================================

INSTALL
1. Drag "Pipette" onto the "Applications" folder in this window.
2. Open your Applications folder and double-click Pipette.
   The first time, macOS will say it can't verify the developer
   (the app is free and isn't from the App Store). To allow it once:
     • macOS 15 Sequoia or newer: click "Done", then open
       System Settings → Privacy & Security, scroll down and click
       "Open Anyway" next to Pipette, and confirm.
     • macOS 14 or older: right-click (Control-click) Pipette →
       Open → Open.
   After that it opens normally with a double-click.

Pipette is a real Mac app: it opens in its own window, with its
own menus, Dock icon and Save/Open dialogs. No browser needed, and it
works fully offline — nothing is uploaded anywhere.
Works on Apple silicon (M1/M2/M3/M4) and Intel Macs, macOS 11 or newer.

YOUR DATA
• Save your project with File → Save (⌘S). After the first time, ⌘S
  saves straight back into the same .pipette file; File → Save As (⇧⌘S)
  makes a copy. Double-click a .pipette file in Finder to open it.
• New Project and Open start clean: if you have unsaved changes, Pipette
  asks whether to save them first (also when you quit). If Pipette ever
  closes unexpectedly, the welcome screen offers to restore your work.
• Coming from the browser version? Save your project there (⌘S), then
  open that .pipette file here.

NEW IN 1.3
• Select like a spreadsheet: drag across cells, Shift-click, or click row
  numbers / column letters (Shift or ⌘ for more). Then:
  ⌫ clears cells or deletes whole rows/columns, ⌘C / ⌘X / ⌘V copy, cut
  and paste blocks, ⌘A selects everything, and right-click shows
  insert / delete / "delete cells and shift up".
• Exclude values like Prism: select them and press ⌘E. They stay visible
  in blue italics with a *, but are left out of analyses and graphs.
• Welcome screen on start, and a proper "Save changes?" question.

NEW IN 1.2
• Delete or insert rows and columns: click a row number (Shift/⌘-click
  for more) and press Delete, or right-click a row number, a cell or a
  column header.
• Multiple comparisons like Prism: compare every pair, each group vs a
  control, or only the pairs you tick — with the matching test
  (Tukey, Dunnett, Šídák, Holm–Šídák, Bonferroni, Fisher's LSD, Dunn).
• Open GraphPad Prism files (.pzfx; .prism is experimental): File → Open
  or Import Prism File (⇧⌘I). The data tables come in — column, grouped
  and survival tables — and you re-make the analyses and graphs here.
